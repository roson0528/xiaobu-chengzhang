# 小步成长 · 家庭学习习惯管理平台（开源脱敏版）

自托管的家庭学习与习惯管理平台，含孩子端 App、家长端 App 与管理后台三端。功能覆盖任务下发与审核、专注监督（摄像头抓拍）、打卡、积分与奖励兑换、作业提交、家庭群聊与私聊、成长报告与导出，以及基于设备 IP/MAC 的联网授权与时间段管控。后端 FastAPI，移动端 Flutter，管理后台 Vue 3。本包已完成脱敏：所有密钥、内网地址与域名均替换为占位符，随附 .env.example 与部署说明。
